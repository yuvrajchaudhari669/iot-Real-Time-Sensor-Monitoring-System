# IoT Real-Time Sensor Telemetry and Anomaly Detection System

An end-to-end telemetry pipeline and monitoring dashboard designed for real-time sensor data ingestion, flow rate monitoring, and automatic threshold violation alerts.

## Features
- Real-time sensor metrics display
- Dynamic anomaly detection against operational baselines
- Interactive temporal data logs and visualization
- Designed for integration with ESP32/microcontroller pipelines over MQTT/HTTP

## Tech Stack
- Python 3
- Streamlit
- Pandas
